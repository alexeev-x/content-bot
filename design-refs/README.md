# Design references

Put owner reference images here, one folder per task: `design-refs/<task>/` (for example `design-refs/post-editor/`). Name files by screen and state, for example `desktop-editor-empty.png`, `phone-editor-media.png`.

Images in this folder are not committed (only this README is). How they are used: `docs/AGENT_UI_WORKFLOW.md` § Reference fidelity.
