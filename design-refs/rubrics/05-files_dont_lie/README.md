# «Утечка недели» (было «Файлы не врут»)

О чём: раз в неделю одна самая интересная конкретная деталь из находок в файлах игры за 7 дней, поданная как утечка («Valve это скрывает»); нет находок — рубрика не выходит.

Что на картинке сейчас: «дело» с номерами сборок, датами и замазанным текстом находок (открыто одно говорящее слово), штамп «Секретно» и две пасхалки в случайных местах.

Статус: одобрена владельцем 26.10.2026 — «Утечка недели»: одна конкретная находка недели словами (сначала что нашли, потом шутка), картинка-«дело» (виды A «Дело», C «Исходник», E «Проводник»; при 1–2 находках только A и C) с двумя пасхалками из запаса. Менять только по новому решению владельца.
