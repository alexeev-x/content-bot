# «Кто теперь имба?»

О чём: герои, ставшие сильнее, чем были (сумма усилений в % больше суммы нерфов); главное усиление каждого словами, без таблицы; опрос «Кто имба?» с одним шутливым вариантом, один ответ, случайный порядок.

Что на картинке сейчас: «измерительная пластина»: заголовок Tektur «Кто теперь имба?», портреты Valve с фоном на стойках над шкалой, высота — самое крупное усиление героя в % (подпись «на N%»), остальной текст Manrope.
