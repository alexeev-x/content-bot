# «Сеты из мастерской»

О чём: сет из мастерской Steam, который за неделю набирает популярность. Своей картинки нет: одно rich-сообщение с каруселью из фото самого сета (скриншоты автора без обрезки, квадратная обложка Steam — только если их нет; GIF-скриншоты анимацией) и гифок из описания (mp4 с imgur), до 10 штук. Текст ИИ — одна-две строки, что за сет и для какого героя, с шуткой. Ниже — вердикт реакциями, случайно один из запаса («🔥 — имба, 💩 — пиздец, 🤤 — обкончай меня, Педро» и др.), и текст-ссылка «Посмотреть в мастерской» (адрес не виден). Видео-роликов YouTube в мастерской Dota у трендовых сетов не нашлось (27.10.2026).

Первый кадр карусели — чёткая статичная картинка героя (скриншот автора, а если все кадры — GIF, то обложка сета), уже 1200 px — улучшается через ИИ (закон о картинках); дальше GIF (512 px, 256 цветов — так в самой мастерской) и ролики.

Сет не повторяется никогда: планировщик пропускает уже выходившие (docs/RUBRICS_SCHEDULER.md); образец на DEV берёт случайный из десятки тренда недели.

Статус: одобрена владельцем 28.10.2026 — как описано выше (начата 27.10.2026: «назовём сеты из мастерской… фотографии и видео из мастерской забирай… ссылки прятать в кнопки или текст»). Менять только по новому решению владельца.
