# «Сеты из мастерской»

О чём: сет из мастерской Steam, который за неделю набирает популярность. Своей картинки нет: альбом из фото самого сета (обложка и скриншоты автора) и гифок из его описания (как видео, mp4 с imgur), до 10 штук. Текст ИИ — одна-две строки, что за сет и для какого героя, с шуткой. Ниже — вердикт реакциями, случайно один из запаса («🔥 — имба, 💩 — пиздец, 🤤 — обкончай меня, Педро» и др.), и текст-ссылка «Посмотреть в мастерской» (адрес не виден). Видео-роликов YouTube в мастерской Dota у трендовых сетов не нашлось (27.10.2026).

Сет не повторяется никогда: планировщик пропускает уже выходившие (docs/RUBRICS_SCHEDULER.md); образец на DEV берёт случайный из десятки тренда недели.

Статус: в работе с 27.10.2026 (владелец: «назовём сеты из мастерской… фотографии и видео из мастерской забирай… ссылки прятать в кнопки или текст»).
