# Design references

This directory contains **visual references only**. They are not screenshots of finished product behavior and they are not contracts for backend/API data.

## Primary external orientation

**Cloudflare Dashboard** — <https://dash.cloudflare.com/>

Use it as a reference for layout behavior and visual restraint:

- calm dark neutral surfaces;
- thin borders;
- dense operational information;
- compact controls;
- collapsible navigation;
- stable sections;
- high-quality structural skeletons;
- tables and charts;
- command-style search.

Do **not** copy Cloudflare branding, logos, proprietary illustrations or wording.

## Files

### `alexeev-design-reference-board.webp`

A compact board of ALEXEEV Studio exploratory concepts produced during design discovery. It covers examples of:

- Overview;
- Posts;
- Editor;
- Publications;
- Incidents;
- Analytics;
- Calendar;
- Media;
- Automations/Cron;
- mobile layouts.

The board is useful for feature placement and composition ideas. **Its bright/neon treatment is superseded by the calmer Cloudflare-like color direction in `../README.md`.**

Some exploratory images may contain future/demo labels or stale concepts. They must not be interpreted as implementation requirements without checking current scope.

## Product scope warning

AI/LLM features are currently out of scope. Ignore any accidental AI/OpenAI/generation/moderation labels in exploratory imagery.

Future/demo metrics are placeholders unless a real source/API is implemented. Never present demo figures as production analytics.
