# Design references

Every file in this directory is a **visual reference only**. This includes website captures, screen mockups, mobile boards, isolated component examples and exploratory layouts. None is a finished product screen, a page template, an interaction contract, or a source of requirements for functions and data.

## Reference the owner liked: Cloudflare Dashboard

[Cloudflare Dashboard](https://dash.cloudflare.com/) is a source of ideas, not a required pattern library or strict specification. The owner called out these qualities as especially convenient:

- The navigation can be collapsed from a control at its bottom, with a smooth transition.
- Loading skeletons look polished and close to the real content; sections do not jump in height when data appears.
- Information is arranged compactly, with clear structure and useful operational detail.

These are preferences to consider and adapt to ALEXEEV's screens, not requirements to copy exact placement, animation, geometry or behavior. The captures may also inspire hierarchy, tables, charts and search. Do **not** copy Cloudflare logos, branding, proprietary illustrations or wording. ALEXEEV's product needs, approved identity and Russian interface language take precedence.

## Scope and interpretation

- The screenshots illustrate concepts and may contain future/demo labels, stale concepts or invented sample data. Nothing in an image becomes a product requirement without explicit product scope and API support.
- AI/LLM functionality is out of scope. Ignore accidental AI, OpenAI, generation or moderation labels.
- Future/demo metrics are placeholders unless a real data source/API exists. Never present demo figures as product analytics.
- Product behavior, security, API contracts and the implementation plan take precedence over every image.
