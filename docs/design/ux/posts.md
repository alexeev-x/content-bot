# §3.2–3.3 Посты, редактор поста

## 3.2 Посты `/posts` (+ `?view=archive`)
- **Purpose:** find a post and open/continue it. **Primary:** «Новый пост» (header; phone: header button).
- **Views (tabs, URL):** Все · Черновики · Архив (count only on Архив). «Все» includes derived states with badges (Черновик, Одобрен, Запланирован + time, Отправляется, Нужна сверка).
- **Desktop:** Header -> Tabs -> Panel{ header: title, «Выбрать», search field; DataTable (checkbox, Пост: title + one-line excerpt, Статус, Изменён, `⋯`; sort by clicking «Пост»/«Изменён») , footer «Загружено 4 из 12 · Показать ещё» }. Case-insensitive substring search matches title, post text, current channel names and displayed status. Search and sort apply on the server to the full selected view before cursor pagination; `view`, `q`, `sort` and `direction` live in the URL. The footer's total is for the current search/view, while the Archive tab badge remains the full archive size. No status filter (the «Черновики» tab covers it). The count line sits in the footer, not floating below the table. Selection: row checkboxes appear in «Выбрать» mode; bulk bar replaces the toolbar.
- **Phone:** Header + «Новый пост» -> Tabs (scrollable never needed, 3 tabs) -> Panel{ Toolbar [search][Сортировка] , cards }. «Сортировка» opens a sheet listing the orders; one tap applies and closes it (no dropdown, no «Показать результаты»); search has the same server-side matching as the desktop table. `Выбрать` stays in the panel header. The list is a chat list (owner, 20.10.2026): no card frame, rows run to the screen edges, the title takes one line with the time of the last change at its right («12:00» today, «пн» this week, «6 окт.», «06.10.25»), the status chip and the send time of a scheduled post under it.
- **Derived list state of a post** (first match wins): archived (`archivedAt` set, only in Архив) → a publication `preparing`/`sending` «Отправляется» or `unknown` «Нужна сверка» (never archived) → a publication `scheduled`/`queued`/`retry_wait` «Запланирован» + nearest time → `approved` «Одобрен» → `draft` «Черновик». Icon plus text, never colour alone.
- **«ИИ» mark (owner, 16.10.2026):** a small muted «✦ ИИ» after the title (phone: before the meta line) on a post made from an approved AI-editor draft; its tooltip and screen-reader text say bot or studio and the edit share. Studio-only: nothing in the post, the channel or for readers shows it.
- **Row `⋯`:** Открыть, Удалить; Архив: Вернуть из архива, Удалить сейчас. Every delete is confirmed: the dialog names the post (or the count), the number of scheduled publications that will be cancelled, and that Telegram messages stay. Rows with a `preparing`/`sending`/`unknown` publication cannot be deleted or selected (reason in a tooltip). Bulk: ≤ 100 per request, per-item result; a partial result toasts «Удалено: N из M. Не удалось: K» and keeps failed rows selected with their reasons. Archive rules (when a post moves there, 30-day purge, restore): `docs/BACKEND_ARCHITECTURE.md` §5 "Post lifecycle as built".
- **States:** 2.5; empty Все: «Пока нет постов» + «Новый пост»; empty Архив: «Здесь будут опубликованные посты 30 дней».

## 3.3 Редактор поста `/posts/new`, `/posts/:id`

Сделанное описано кодом (`apps/frontend/src/features/posts`) и решениями в `docs/DECISIONS.md` (16–18.10.2026: без заголовка, опрос — отдельный тип поста, параметры отправки на шаге «К публикации»).

**Инварианты:** правило неизменяемой одобренной ревизии, `409 STALE_REVISION`, сверка неопределённой публикации и подтверждение владельца перед отправкой важнее макетов. Кнопка **«К публикации»** открывает существующий шаг выбора канала/времени.

**Телефон (< 860 px, владелец 20.10.2026: «как в Telegram»):** `PhoneComposer` — экран-колонка по высоте видимой области (`visualViewport`, в Mini App ещё `viewportChanged`): шапка (назад, название и статус сохранения, `⋯`: у нового поста — тип «Текстовый пост / Опрос», у сохранённого — удаление), фон чата, пост — пузырь сообщения канала (медиа сверху, заголовок старого поста жирной первой строкой, текст редактируется прямо в пузыре, время сохранения и ✓), внизу панель 📎 Aa 😀 ✨ и «К публикации». 📎/Aa/😀 открывают панель на месте клавиатуры её последней высоты (до первой клавиатуры — 40 % экрана, 240–360 px): медиа (галерея, камера, медиабиблиотека), все действия форматирования плитками, эмодзи без поиска; повторное нажатие (иконка клавиатуры) возвращает клавиатуру, Esc закрывает. Колонка повторяет видимую область; высота пишется прямо в стиль, без перерисовки редактора. В Telegram на iPhone высота берётся из `viewportChanged`: он приходит в начале движения клавиатуры, а сама страница меняет размер только через ~0,4 с (замеры владельца 20.10.2026); колонка плавно едет к этой высоте. Угадывать высоту клавиатуры нельзя — догадка спорила с настоящей, и панель дёргалась. Эмодзи в панели — обычные кнопки: сотни кнопок React Aria рисовались ~0,25 с. ✨ открывает «Улучшить через ИИ». Опрос — тоже пузырь (`PhonePoll`): вопрос и варианты печатаются прямо в нём, «Ввод» переходит к следующему полю (вопрос и варианты — одна строка, перенос из буфера становится пробелом), у варианта ручка перемещения и ×, «Добавить вариант» внизу пузыря; в панели ⚙ «Несколько ответов» и «Режим викторины»; в викторине верный ответ выбирается кружком у варианта, пояснение — строкой под вариантами. Одобренный и архивный пост на телефоне — прежний вид: превью и публикации.

**Не сделано:**
- Приёмка владельцем на DEV после правок 18.10.2026: desktop 1280/1920, телефон в браузере и в Mini App; мобильный редактор 20.10.2026 проверен только на моках в Chrome — на iOS Safari, Android Chrome и в Telegram iOS/Android не проверен.
- iOS: `--visual-viewport-height` в стилях диалогов и нижних листов нигде не задаётся — экранная клавиатура может закрыть их низ (мобильный редактор от этого не зависит).
- Одобренный пост показывает только превью и публикации: опрос и параметры отправки в режиме «только чтение» в редакторе не открываются.
- «Написать через ИИ» из студии — отдельный будущий сценарий, не часть «Улучшить через ИИ».
- Телеметрия «Улучшить через ИИ»: принято / отменено / выбранное действие (сейчас считаются только траты).
- Список публикаций: у удалённого поста-опроса снимок без типа, строка пишет «Без текста» вместо метки «Опрос» (нужно поле в контракте публикации).
