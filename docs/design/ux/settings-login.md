# §3.6–3.8 Настройки, вход, 404 / «Раздел в разработке»

## 3.6 Настройки `/settings/*`
- **Purpose:** rare configuration. Master/detail: desktop list 200 px + detail; phone list -> detail with «‹ Настройки». The Settings page title is `h1` «Настройки»; section title is `h2` in the detail Panel header strip.
- **Каналы (primary: «Добавить канал», in the detail header, next to the title):** Panel list rows (avatar, name (wrap anywhere, 2 lines), ID mono muted, status chip «Работает / Нет прав / Недоступен», chevron). Row opens the channel Drawer (desktop) / sheet (phone). Add channel = dialog (desktop) / full-screen sheet (phone): step 0 hint «Сначала добавьте бота администратором канала», input, «Проверить» (Enter works), result card (name, rights), «Сохранить канал» footer (button name differs from the opener; `unknown`? n/a).
- **Оформление (14.10.2026):** «Тема» as three tiles with a mini illustration (Светлая · Тёмная · Как в системе); «Цвет» as a grid of 8 labelled tiles (one accent for both themes) with a live preview (nav item, button, status, link, Telegram bubble); «Плотность» Обычно/Компактно. Every choice saves immediately; no Save button, no custom colours.
- **ИИ (17.10.2026, `design-refs/ai-settings/`):** a status card (mark, provider, status pill, next step, last check; «Включён» switch and «Проверить» on the right); then «Расходы и лимиты» beside «Качество за 30 дней» (side by side from a 720 px detail, stacked below), each with figure tiles (`StatGrid`/`StatTile`); «Качество» warns «Одобряете мало черновиков» below 30 % approvals over at least 5 drafts; «Модели и задачи» full width; «Бюджет» (three choice rows) beside «Голос и правила»; the price list folded at the end. Only real data: no log of checks, no rules editor, no channel post counts. «Качество» ends with sections that load when opened: «История черновиков» (each first draft titled by its task on two lines at most, with format · bot or studio · time · versions · «Одобрен» · «Есть ваша версия» · verdicts · cost; opening it lists every version with its kind, time, model and cost, the editor's question if it asked one, each text labelled «Текст ИИ», «Ваша версия» or «Одобрено» (the owner's texts marked by an accent rule) and the verdicts; «Показать ещё» for older drafts), «Правила редактора» (AI plan P8: each rule's text, scope · source · state, for an analysis rule «Роликов выше обычного: N · ниже: N» and a nested «Ролики (N)» with each script's start, «Выше/Ниже обычного», «до правила» and «Убрать»; an owner rule has the «Учитывать» switch, a supported analysis rule «Учитывать» / «Нет», one in use «Отключить»; a closed rule stays listed muted with no control; a refusal says why under the rule), «На чём учится ИИ», «Сценарии без видео».
- **Общие (17.10.2026, `design-refs/general-settings/`):** «Связь с ботом» card (mark, state, the bot's name with copy and «Открыть чат», tiles: webhook address, pending updates, last delivery error; the connect panel when not connected); «Часовой пояс» with the clock in that zone; «Уведомления» rows with a coloured mark per kind, «Включить всё», the always-on critical notice. Patch watchlists and «Быстрые действия» were removed (owner, 17.10.2026): «Следить» in «Источники» keeps working, but the list of watches is no longer shown. The reference's help guide, uptime and message statistics have no data and are left out.
- **States:** channels loading skeleton 3 rows, error, empty («Каналов пока нет» + «Добавить канал»), channel `no rights` warning chip + «Проверить права», save conflict, quick-save revert toast.

## 3.7 Вход `/login`
Centred card (max 400 px), logo, h1 «Вход», Telegram Login Widget button as the only primary; below: muted «Только для владельца». States: widget loading (reserved 48 px slot), cancelled, expired («Ссылка устарела, войдите снова»), 401, 403 foreign owner («Нет доступа к этой панели»), `Retry-After` countdown (existing `RetryAfterButton`). Mini App: no screen, auto sign-in shows shell skeleton; failure shows the same card with «Повторить». Phone: card fills width with 16 px margins, widget centred.

## 3.8 404 / «Раздел в разработке»
404: h1 «Страница не найдена», one sentence, button «К обзору». Stubs are unreachable from nav; if reached by URL: «Раздел в разработке» + button «К публикациям» (nearest working view).
