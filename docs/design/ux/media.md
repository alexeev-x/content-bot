# §3.10 Медиатека

## 3.10 Медиатека `/media`
- **Purpose:** find retained media and attach it to a draft without exposing storage URLs or copying bytes.
- **Data:** owner-only `GET /api/v1/media` provides keyset-paginated retained assets, filename substring search (case-insensitive, Cyrillic included), kind and current-usage filters, metadata, exact-byte duplicate count and bounded current-post links. `GET /api/v1/media/{mediaId}/content` is the private preview source. A file may be retained only by immutable post history and therefore have no current post link.
- **Actions:** search by part of the filename; filter All / Photos / Video and All / Used / Unused; switch Grid / List; open an inspector with authenticated preview, metadata, duplicate count and current post links; select one or more assets and attach them to an existing draft through `POST /api/v1/posts/{id}/media/attach`. Draft selection and attachment never publish or schedule. A 409 keeps the selection and offers a safe draft refresh. «Создать пост» opens the existing editor route; files are uploaded only from a draft editor.
- **Unavailable actions:** no standalone library upload, tag editing, public download URL or manual deletion. The list contains retained assets that are already referenced; automatic cleanup alone removes assets after checking current links and immutable revisions.
- **States:** loading = geometry-matched skeleton; empty library = «Файлов пока нет» with «Создать пост»; filtered-empty = «Ничего не найдено» with reset; network/5xx = error + request id + safe GET retry; 401 redirects through shared session expiry and clears private media cache; 403 shows no media metadata or bytes; stale draft revision = 409, keep selection and offer reload; missing preview object = item remains visible with preview unavailable and retry only for safe GET.
- **Navigation/focus:** page route changes update the title and focus the H1; inspector close restores focus to its opener; attaching closes only after server success and announces the result. Escape closes dialogs/inspector and returns focus to the trigger.
- **Responsive/accessibility:** grid has two columns on phone; inspector becomes a bottom sheet; list becomes compact rows. Search, tabs, selection and attachment work by keyboard; touch targets follow 44 px project minimum. No horizontal page overflow at 320 px; full viewport matrix and axe/keyboard checks are required.
- **G/W/T:** Given an asset is retained only by an immutable revision, When the owner opens it, Then it is listed with no current-post link and cannot be manually deleted. Given the owner attaches a selected asset to a draft and the server returns 409, Then no success is shown, the selection remains, and no publication is created.
