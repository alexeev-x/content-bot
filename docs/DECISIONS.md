## Ждут решения владельца
| Вопрос | Рекомендация по умолчанию |
|---|---|
| UI-библиотека | React Aria Components + своя монохромная тема (запасной вариант — HeroUI v3) |
| Cron-only или Cron + Queue для MVP | Cron-only до замера нагрузки |
| Вход в админку | Cloudflare Access (один владелец) вместо собственного OTP |
| Генерация текста через AI | не входит в MVP |
| Подписи статусов публикаций | таблица в skill `page-spec` |
| Повтор `Idempotency-Key` с другим телом | 409 `CONFLICT` с `details.reason` |
| Устаревшая ревизия черновика | ревизия в теле запроса → 409 (без заголовка `If-Match`) |
| Telegram Mini App в MVP | отложить, сначала адаптивный веб |
